# 리서치 데스크 (Research Desk)

매일/매주 투자 리서치를 기록하는 개인 지식관리 웹앱입니다. 서버 없이 **깃헙 페이지(GitHub Pages)** 정적 호스팅으로 동작하고, 데이터는 **브라우저(localStorage)** 에 저장됩니다.

## 구성

| 번호 | 섹션 | 주기 |
|---|---|---|
| 01 | 뉴스 | 매일 |
| 02 | 시황 영상 요약 | 매일 |
| 03 | 텔레그램 스크리닝 | 매일 |
| 04 | 독서 | 주 1회 |
| 05 | 리포트 · 종목분석 | 주 1회 |
| 06 | 섹터 딥리서치 | 주 1회 이상 |

- **오늘 대시보드**: 매일·주간 루틴의 완료 여부, 연속 기록일, 최근 기록을 한눈에.
- **리치 텍스트 에디터**: 노션·블로그 등에서 복사한 내용을 **서식·아이콘 그대로** 붙여넣기. (제목·굵게·목록·인용·링크·코드 지원)
- **내 생각** 영역: 붙여넣은 내용과 별도로 나만의 해석/판단을 구분해 기록.
- **태그 · 전체검색**(Ctrl/⌘+K) · **라이트/다크 모드**.
- **백업**: JSON 내보내기/가져오기, 마크다운(.md) 내보내기.

## 깃헙 페이지로 배포하기

1. 새 저장소를 만듭니다. 예: `research-desk` (Public 권장).
2. 이 폴더의 `index.html`, `styles.css`, `app.js` 를 저장소 **루트**에 올립니다.
   ```bash
   git init
   git add index.html styles.css app.js README.md
   git commit -m "Add research desk"
   git branch -M main
   git remote add origin https://github.com/<사용자명>/research-desk.git
   git push -u origin main
   ```
3. 저장소 → **Settings → Pages** → *Build and deployment* 의 Source를 **Deploy from a branch**, Branch를 **main / (root)** 으로 설정 후 저장.
4. 1~2분 뒤 `https://<사용자명>.github.io/research-desk/` 에서 열립니다.

> VS Code에서 그대로 열어 수정 후 `git push` 하면 사이트가 자동 갱신됩니다.

## 데이터 저장에 대해 (중요)

- 기록은 **그 브라우저 안에만** 저장됩니다. 깃헙에는 올라가지 않습니다(앱 코드만 올라감).
- 즉 **PC를 바꾸거나 브라우저 데이터를 지우면 기록이 사라집니다.** 정기적으로 **백업 · 설정 → JSON 백업**을 눌러 파일로 저장해 두세요. 새 환경에서는 같은 메뉴의 *가져오기*로 복원합니다.
- 저장 한도는 브라우저당 약 5MB입니다. 텍스트 위주면 수년치도 충분하지만, **용량 큰 이미지를 붙여넣으면 한도를 빠르게 소진**하니 이미지는 작게 쓰거나 링크로 거는 편이 안전합니다.

## 나중에 기기 간 동기화가 필요해지면

깃헙 토큰을 이용해 기록을 저장소의 JSON/마크다운 파일로 자동 커밋하도록 확장할 수 있습니다(폰·PC 동기화 + 버전 기록). 지금 구조(`state.entries` 단일 배열)는 그 확장을 염두에 두고 설계돼 있으니, 필요하면 그때 추가하면 됩니다.
